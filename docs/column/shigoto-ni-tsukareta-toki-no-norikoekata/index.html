仕事に疲れた時の乗り越え方｜心が軽くなる7つのヒント

2026年8月7日（金）

「今日はもう限界かもしれない」——仕事に追われる毎日の中で、そんな風に感じる瞬間は誰にでもあります。ここでは、心が少しでも軽くなるための7つのヒントをご紹介します。

1. 「頑張れない日」があってもいいと認める

毎日同じペースで頑張り続けられる人はいません。今日は思うように動けなかったとしても、それは怠けているのではなく、それだけ普段から頑張ってきた証拠です。

2. 今日やったことを、できなかったことより先に数える

1日の終わりに、つい「できなかったこと」ばかりが気になってしまう方は、あえて「今日できたこと」を先に3つ挙げてみてください。小さなことで構いません。

3. 昼休みは仕事の話題から離れる時間にする

休憩時間まで仕事のことを考え続けていると、心が休まる時間がなくなってしまいます。ほんの数分でも、仕事とは関係のない話題や景色に目を向ける時間を作ってみましょう。

4. 「全部自分でやらなきゃ」を一度手放してみる

責任感が強い人ほど、一人で抱え込みやすい傾向があります。頼れる部分は誰かに頼る、相談してみる——それは弱さではなく、うまく仕事を続けるための工夫の一つです。

5. 帰り道に、仕事以外のことを考える時間を作る

通勤や帰宅の時間を使って、好きな音楽を聴いたり、今日の夕食を考えたりと、意識的に仕事から気持ちを切り替える時間を持ってみましょう。

6. 「比べる相手」を過去の自分だけにする

周りの同僚や同世代と自分を比べて落ち込んでしまうときは、比べる対象を「1年前の自分」に変えてみてください。小さな成長でも、きっと見つかるはずです。

7. 仕事を辞めたくなるほど疲れたら、まず休むことを考える

「もう無理かもしれない」と感じるほど疲れているときは、大きな決断を急ぐ前に、まずしっかり休むことを最優先にしてください。心身の状態が続くようであれば、専門機関に相談することも大切な選択肢です。
