感謝日記のつけ方｜今日からできるジャーナリング入門

2026年8月4日（火）

「感謝日記」という言葉を聞いたことはありますか。1日の終わりに、感謝できることを少しだけ書き出す——たったそれだけの習慣ですが、続けるうちに物事の見方が少しずつ変わっていきます。

1. ノートとペンを、寝る場所の近くに置いておく

続けるコツは、始めるハードルをできるだけ下げることです。ノートとペンをベッドサイドなど、目につく場所に置いておきましょう。

2. 「今日感謝できること」を3つだけ書く

1日の終わりに、その日あった「ありがたいこと」を3つだけ書き出してみてください。多く書く必要はありません。

3. 大きな出来事でなく、小さなことに目を向ける

「おいしいコーヒーが飲めた」「電車に間に合った」など、日常のささやかな出来事こそが、感謝日記の良い題材になります。

4. 完璧に書こうとせず、単語だけでもいい日を作る

文章にまとめる余裕がない日は、「晴れ」「友人」のような単語を書くだけでも構いません。続けることを何より大切にしてください。

5. 毎日でなくても、週に数回から始めてみる

毎日続けることにこだわりすぎず、まずは週に2〜3回から始めてみるのもおすすめです。無理のないペースが、長く続ける秘訣です。

感謝日記は、幸せを探す練習

感謝日記は、特別な出来事を待つための習慣ではなく、すでにある小さな幸せに気づくための練習です。今夜、3行だけ書いてみませんか。
