自己肯定感を高める方法｜今日から始められる小さな習慣

2026年8月6日（木）

「自分に自信が持てない」「つい自分を責めてしまう」——そう感じるとき、自己肯定感は特別な誰かだけが持っているものではなく、日々の小さな習慣で少しずつ育てていけるものです。

1. 「できたこと」を1日1つ、書き出してみる

どんなに小さなことでも構いません。「今日は早起きできた」「ちゃんとご飯を作れた」——そうした小さな達成を、意識して数える習慣をつけてみましょう。

2. 自分に対する言葉づかいを、友人にかけるように変えてみる

失敗したとき、自分にどんな言葉をかけていますか。もし友人が同じ失敗をしたら、あなたはもっと優しい言葉をかけるはずです。自分自身にも、同じやさしさを向けてみましょう。

3. 完璧を目指さず、「60点でよし」とする日を作る

何事も100点を目指し続けると、心も体も休まりません。あえて「今日は60点で合格」と自分に許可を出す日を、意識的に作ってみてください。

4. 他人と比べる時間を、自分の変化を見る時間に変える

SNSなどで他人と自分を比べてしまうときは、代わりに半年前・1年前の自分と今の自分を比べてみましょう。気づかないうちに成長している部分が、きっと見つかります。

5. 「ノー」と言うことを、自分を大切にする選択として捉える

頼まれごとを断れずに疲れてしまう方は、「ノー」と言うことは冷たいことではなく、自分の時間や心を守るための大切な選択だと捉え直してみましょう。

6. 小さな成功体験を、意識して積み重ねる

大きな目標だけでなく、今日中に終えられる小さな目標を立てて、それを達成する経験を積み重ねていくことも、自己肯定感を育てる助けになります。

自己肯定感は、少しずつ育てていくもの

一夜にして自分を好きになる必要はありません。今日紹介した中から、続けられそうなことを1つだけ選んで、少しずつ試してみてください。
